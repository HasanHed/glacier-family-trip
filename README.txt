GLACIER FAMILY TRIP WEBSITE

FILES
- index.html: the complete self-contained website. All illustrated route cartoons are embedded in this file.

OPEN LOCALLY
1. Unzip the package.
2. Double-click index.html.
3. It will open in your web browser.

PERMANENT HOSTING RECOMMENDATION
Use GitHub Pages for a stable public URL and version history.

UPDATING LATER
When ChatGPT gives you a revised index.html:
1. Replace the old index.html in your GitHub repository.
2. Commit the change.
3. GitHub Pages automatically republishes the same website URL.

PRIVACY
A GitHub Pages website is publicly accessible. Do not include private information in the page.
